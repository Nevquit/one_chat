Monorepo 顶级工作区

六边形架构核心依赖铁律

1. 核心层零外部依赖 (core/)

models.py 与 ports.py 仅依赖 Python 标准库与 Pydantic，绝对不导入 LangChain、httpx 或任何数据库 SDK。

2. 依赖倒置 (Ports & Adapters)

routing/、knowledge/、bridge/ 仅通过 ports.py 定义的 Protocol 接口工作；具体实现全部收口在 adapters/ 中。

3. 评测单向隔离 (evaluation/)

顶级 evaluation/ 可导入 src/ 的模型进行断言，但 src/ 严禁反向依赖 deepeval 或 ragas，保证生产镜像轻量纯净。

Routing（意图路由层）

src/wanchain_agent/routing/
无状态 / 局部决策

好比医院的“导诊台”或铁路的“转辙机”。它只专注于回答一个问题：“用户这句话想干什么，应该去哪？”

  • 规则优先 (rules.py)：正则/关键词毫秒级拦截高频明确意图。
  • LLM 兜底 (classifier.py)：输出严格 Pydantic 结构 RoutingDecision 与槽位参数。
  • 边界清晰：不查文档、不算跨链、不管理长对话状态。

Orchestration（编排中枢层）

src/wanchain_agent/orchestration/
有状态 / 全局总导演

好比整个应用的“控制中枢与总导演”。它统一调度 Routing、Knowledge 和 Bridge 节点，控制“按什么顺序走、何时暂停、如何恢复”。

  • 全局状态机 (GraphState)：持有上下文消息、路由决策、交易预览等全量状态。
  • 调度下游模块：阶段三的 RAG 检索与 Bridge 校验均由编排层的条件边触发调用。
  • Human-in-the-loop：跨链前触发 interrupt() 冻结状态至 Redis，等待钱包签名后唤醒。
