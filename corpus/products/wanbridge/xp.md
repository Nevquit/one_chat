
# XP

Wanchain’s XP is a non-transferable reputation system that tracks and measures user participation throughout the Wanchain ecosystem. XP is earned automatically whenever a user completes a cross-chain transaction using one of Wanchain’s cross-chain products, such as [WanBridge](https://docs.wanchain.org/products/wanbridge.md) and [XFlows](https://docs.wanchain.org/products/xflows.md).&#x20;

XP is earned with each cross-chain transactions, based on the following formula:

* 100 XP per cross-chain transaction
* 1 XP for every $1 value transferred
* 100 XP for every $1 value of [bridge fees](https://docs.wanchain.org/the-convert-n-burn-system/bridge-fees.md) paid

XP cannot be sold or moved between wallets. XP can be used to claim [Bridge-to-Earn](https://docs.wanchain.org/products/wanbridge/bridge-to-earn.md) tasks and earn rewards. Other use cases are in development.
